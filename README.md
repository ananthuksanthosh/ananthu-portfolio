# Ananthu K Santhosh - Portfolio

Static portfolio website (plain HTML, CSS and JavaScript). No build step.

## Files

- `index.html` - the whole website
- `assets/about-infographic.png` - About section illustration
- `vercel.json` - Vercel settings
- `Resume.pdf` - add your resume here (the Download Resume button links to it)

## Run locally

Open `index.html` in a browser.

## Deploy

1. Push this folder to a GitHub repository.
2. On vercel.com choose Add New > Project and import the repository.
3. Framework Preset: Other. Leave Build Command and Output Directory empty.
4. Click Deploy.
